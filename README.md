# 诉讼请求分项计算说明

给准备庭审或向法院说明金额的办案人员使用。按现行诉请逐项整理请求权基础、计算明细和证据页码，并核对交付成稿中的分项与合计。

## 安装

下载本仓库的 ZIP 并解压，将包含 `SKILL.md`、`agents/` 和 `references/` 的目录命名为 `litigation-claim-calculation`，放入个人 Codex 技能目录（通常是 `~/.codex/skills/`）。在新对话中用技能名调用。

## 使用示例

> 请用 $litigation-claim-calculation，根据本案当前起诉状和证据册，逐项列明请求权基础、计算明细和证据位置。先核对原诉请与复算金额的差异，等我确认口径后再出法院说明稿。

可以先看[虚构数据的分段计费与回款示例](references/worked-example.md)。其中还演示了庭审中如何用时间轴说明到期和起算。涉及跨期结余或诉请调整时，参见[跨期结算与新旧金额对照](references/reconciliation.md)。

## 使用条件

本仓库包含技能指引、界面说明和虚构示例。用于具体案件时，使用者需自行提供材料，并配置技能中按任务引用的法律检索服务及相关专项技能。缺少核验条件时，应列出待核事项，保留金额和法源的证据边界。
